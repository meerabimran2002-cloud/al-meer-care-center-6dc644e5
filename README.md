Admin Login (Development)

Use environment variables instead of hardcoding credentials. For example:

Email: admin@almeerhospital.com

Password: stored securely as a hashed value


Agar baad mein tum apna Gmail use karna chahti ho, to usay secure environment variables aur proper authentication ke through configure kiya ja sakta hai, na ke code mein password likh kar.
